# Roadmap

## Milestone 1 - Core Metadata Model

Goal:

Build the foundational concepts used by every future feature.

Deliverables:

- Workspace
- Entity
- Field
- Record
- Relationship
- Effect Schemas
- Domain package

Status:

Planned

---

## Milestone 2 - Data Management

Goal:

Allow users to manage data through configurable entities.

Deliverables:

- CRUD operations
- Search
- Filters
- Sorting
- Views
- Data validation

Status:

Planned

---

## Milestone 3 - Templates and Documents

Goal:

Generate reusable documents from data.

Deliverables:

- Template engine
- PDF generation
- HTML generation
- Print support

Examples:

- Invoices
- Quotations
- Certificates
- Contracts

Status:

Planned

---

## Milestone 4 - Reporting

Goal:

Provide insights from stored data.

Deliverables:

- Aggregations
- Metrics
- Charts
- Dashboards

Status:

Planned

---

## Milestone 5 - Workflows

Goal:

Allow users to model business processes.

Deliverables:

- State machines
- Transitions
- Approval flows
- Workflow history

Status:

Planned

---

## Milestone 6 - Synchronization

Goal:

Synchronize data across devices.

Deliverables:

- Change log
- Sync engine
- Conflict resolution
- Cloud providers

Status:

Planned

Bring Stapler to mobile devices.

Planned

Planned
