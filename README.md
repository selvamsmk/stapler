# Stapler

Stapler is a local-first platform for building custom business applications.

Users define entities, relationships, forms, templates, workflows, and reports through metadata rather than code.

Examples:

- Inventory Management
- Billing Systems
- CRM
- Asset Tracking
- Clinic Management
- School Administration

## Principles

- Local First
- Offline First
- Metadata Driven
- Open Source
- Cross Platform
